Jak přidat CzechGod Kodi repository

Jednoduchý postup pro instalaci repository a následnou instalaci addonů v Kodi.

  1. Povol neznámé zdroje

    Settings → System → Add-ons

    Zapni Unknown sources / Neznámé zdroje.

  2. Přidej zdroj repository

    Settings → File manager → Add source

    Klikni na <None> a zadej:

    https://czechgod.github.io/kodi-addons/

    Zdroj pojmenuj například CzechGod.

  3. Nainstaluj repository ze ZIP souboru

    Settings → Add-ons → Install from zip file

    Vyber zdroj CzechGod a následně ZIP repository:

    repository.czechgod/repository.czechgod-1.0.2.zip

    Počkej na oznámení Add-on repository installed.

  4. Otevři repository

    Add-ons → Install from repository → CzechGod Repository

  5. Nainstaluj addon

    V repository vyber požadovaný addon a klikni na Install.

Automatické aktualizace

Po instalaci repository už není potřeba nové verze addonů instalovat ručně přes ZIP. Kodi získává informace o dostupných verzích z repository a může addon automaticky aktualizovat.
