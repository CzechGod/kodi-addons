# CzechGod Kodi Add-ons

Kodi repository pro instalaci a automatické aktualizace mých Kodi addonů.

## Instalace repository

### 1. Povol neznámé zdroje

V Kodi otevři:

**Settings → System → Add-ons**

Zapni **Unknown sources / Neznámé zdroje**.

### 2. Přidej zdroj repository

Otevři:

**Settings → File manager → Add source**

Klikni na `<None>` a zadej:

```text
https://czechgod.github.io/kodi-addons/
```

Zdroj pojmenuj například **CzechGod**.

### 3. Nainstaluj repository

Otevři:

**Settings → Add-ons → Install from zip file**

Vyber zdroj **CzechGod** a následně:

```text
repository.czechgod-1.0.0.zip
```

Počkej na oznámení **Add-on repository installed**.

### 4. Otevři repository

Otevři:

**Add-ons → Install from repository → CzechGod Repository**

### 5. Nainstaluj addon

Vyber požadovaný addon a klikni na **Install**.

## Aktualizace

Po instalaci repository už není potřeba nové verze addonů instalovat ručně přes ZIP.

Kodi získává informace o dostupných verzích z repository a může nainstalované addony automaticky aktualizovat.
